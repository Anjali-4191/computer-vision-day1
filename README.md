# Computer Vision – Day 1

This repository contains my **Computer Vision Day 1 assignment**, completed using **Python and OpenCV**. The assignment covers basic concepts and practical operations used in image processing and computer vision.

## 📌 About the Project

The purpose of this assignment is to understand the fundamentals of working with images using OpenCV. It includes reading, displaying, analyzing, modifying, and processing images using Python.

## 🛠️ Technologies Used

* **Python**
* **OpenCV**
* **NumPy**

## 📂 Project Files

* `image.py` – Contains the Python code for the Computer Vision questions.
* `image.jpeg` – Input image used for performing image processing operations.
* `README.md` – Documentation of the project.

## 🔍 Topics Covered

The assignment includes various basic Computer Vision operations such as:

* Reading an image using OpenCV
* Displaying an image
* Checking whether an image is loaded successfully
* Finding image dimensions
* Checking image shape and size
* Image resizing
* Image cropping
* Color space conversion
* Grayscale image processing
* Image transformations
* Basic image enhancement
* Saving processed images
* Other fundamental OpenCV operations

## ▶️ How to Run

1. Install Python on your system.
2. Install OpenCV using:

```bash
pip install opencv-python
```

3. Make sure `image.py` and `image.jpeg` are in the same folder.
4. Run the Python file:

```bash
python image.py
```

## 📷 Input Image

The project uses `image.jpeg` as the input image for performing different Computer Vision operations.

## 🎯 Objective

The main objective of this assignment is to gain practical experience with **OpenCV and basic image processing techniques** and understand how images can be handled programmatically using Python.
